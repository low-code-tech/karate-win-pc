# Karate Win — 空手 試合管理システム

空手組手の試合を運営・記録・表示するための、**完全ローカル動作**の Web アプリケーションです。
インストール不要・外部サーバー不要で、HTML ファイルをブラウザで開くだけで動作します。

- 動作環境：**Google Chrome / Microsoft Edge**（最新版推奨・PC）
- ネットワーク：**基本オフラインで動作**。更新確認・最新版ダウンロード時のみオンライン接続を使用します。
- 配信 URL：<https://karate-win-pc.vercel.app/>

---

## 📁 ファイル構成

本リポジトリは以下の 3 ファイルで構成されています。

| ファイル名 | 種別 | 役割 |
| --- | --- | --- |
| `karate-all-in-one.html` | 本体アプリ | 操作画面（採点・タイマー・記録・選手選択など） |
| `karate-monitor.html` | 観客用モニター | 観客／会場ディスプレイ向けの表示専用画面 |
| `keiko-studio.html` | 稽古分析ツール | 手本動画と自分の動画を並べて比較・分析するための練習支援アプリ |
| `version.json` | 更新マニフェスト | 最新バージョン情報を配信するための設定ファイル |

## 1. `karate-all-in-one.html`（本体アプリ）

大会運営の中核となる操作画面です。1 ファイルに全機能を内包しており、これ単体で動作します。

### 主な機能
- **試合タイマー**：試合時間の設定・開始・停止・リセット、15 秒／終了ブザー
- **採点**：有効（1 点）・技有（2 点）・一本（3 点）・反則、先取表示、合計得点の自動計算
- **勝敗判定**：通常勝ち／判定勝ち／勝ち（相手反則）／勝ち（相手棄権）、副審旗による判定ポップアップ
- **選手選択**：Excel から取り込んだ選手データを、クラス・コートで絞り込んで赤／青に割り当て
  - **敗者自動マーク**：勝者ボタンを押すと、相手（敗者）を自動的に「敗退」としてマークし、次回以降の選手選択で選べないよう表示（トーナメント運用向け）
- **Excel 入出力**：選手データの取り込み・テンプレート出力・試合結果の書き出し（SheetJS をインラインで内蔵し、完全オフラインで動作）
- **カメラ録画**：試合の録画・保存（任意）
- **左右反転（⇄）**：赤・青の表示位置を入れ替え（記録内容は不変）
- **インターバル／告知オーバーレイ**：休憩や「決勝・準決勝」などの案内表示
- **観客モニター連携**：後述の `karate-monitor.html` へ、同一ブラウザ内でリアルタイム同期
- **オンライン更新チェック**：トップバーの「更新確認」から最新版の有無を確認・ダウンロード（後述）

### データの保存について
選手データ・試合結果・各種設定は、ブラウザの **localStorage** に保存されます。

- 同じ **PC・同じブラウザ**で開く限り、再起動後もデータは保持されます。
- 別ブラウザ・別 PC・シークレットウィンドウでは共有されません。
- ブラウザの「閲覧データの削除」でサイトデータを消すと失われます。

## 2. `karate-monitor.html`（観客用モニター）

会場の大型ディスプレイやプロジェクター向けの、**表示専用**画面です。
本体アプリと **BroadcastChannel API（チャンネル名 `karate-win-sync`）** で同期します。

### 特徴
- **表示内容**：大会名・クラス・コート・両選手（ゼッケン／氏名／よみがな／所属）・得点内訳・合計・先取・タイマー・勝利バナー
- **リアルタイム同期**：本体アプリの操作が即座に反映（左右反転・インターバル・告知・勝敗も連動）
- **16:9 最適化**：TV／HDMI 出力でもレイアウトが崩れない固定比率表示
- **クリックで全画面化**：ブラウザ UI を隠して大画面に最適化（解除は ESC キー）
- **自動フォント調整**：長い氏名・大会名・勝者名を枠内に自動縮小して表示

### 利用条件（重要）
- 本体アプリと **同一の PC・同一ブラウザ**で開いてください（BroadcastChannel は同一ブラウザ内でのみ通信します）。
- 本体アプリ側のトップバー「**モニター起動**」ボタンから開くのが確実です。
- 別ウィンドウ／別タブへ移動し、会場ディスプレイ側に全画面表示する運用を想定しています。

## 3. `keiko-studio.html`（稽古スタジオ）

空手の技術向上を目的とした、動画比較・動作分析ツールです。
手本動画と自分の演武動画を同時に表示し、再生速度変更・コマ送り・ループ再生・骨格トラッキングなどを利用して技術分析を行えます。

### 主な機能
#### 動画比較
- 2画面同時表示
- 手本動画（YouTube）と自分の動画を並べて比較
- 同時再生・同時停止
- 左右独立操作

#### 動画再生支援
- 再生／停止
- 5秒送り・戻し
- コマ送り・コマ戻し
- 再生速度変更（0.25倍 ～ 1.0倍）
- A-Bループ再生
- ミラー表示（左右反転）

#### 骨格トラッキング
MediaPipe Pose Landmarker を利用した骨格検出機能を搭載しています。

- 骨格描画表示
- 最大2名まで同時検出
- 精度モード切替
  - 速さ優先（Lite）
  - 標準（Full）
  - 最高精度（Heavy）

#### 組手や形の動きを可視化し、姿勢やフォームの確認を行えます。
##### ハイライトマーク
動画内の重要シーンへマークを付けることができます。
- 任意位置へのマーキング
- 前後のマークへ移動
- ローカル保存
- Karate Win の試合イベントとの連携

#### 動画ライブラリ
##### YouTubeライブラリ
- YouTube URL 登録
- タイトル自動取得
- ローカル保存
##### マイライブラリ
- MP4 等の動画URL登録
- 自分専用ライブラリ管理
- ワンタップ再生
#### 重ね比較機能
画面2では複数動画を重ねて比較できます。
- 動画の重ね表示
- 透過率調整
- フォーム比較
- 動作差分確認

### Karate Win 連携
keiko-studio.html は Karate Win の Supabase 環境と連携します。

#### 利用可能な機能
- Karate Win アカウントでログイン
- 参加大会動画の参照
- 試合動画の再生
- ハイライトイベント表示
- 会員向け動画の視聴

#### 対応データ
動画ライブラリから以下の情報を利用できます。
- 大会名
- クラス
- 赤選手／青選手
- 試合日時
- ハイライトイベント
- 試合動画

### 動作環境
#### 推奨ブラウザ
- Microsoft Edge
- Google Chrome
#### スマートフォン対応
- Android
- iPhone
- iPad

レスポンシブ対応により、縦向き・横向きの両方で利用できます。

### 注意事項
#### YouTube再生について
YouTube の仕様により、HTMLファイルを直接開いた場合（file://）は動画を再生できません。
利用する場合は Webサーバー上に配置してください。

#### 骨格トラッキングについて
骨格検出は MediaPipe を利用するため、初回利用時にインターネット接続が必要です。
また、動画配信元によっては CORS 制限により骨格分析が利用できない場合があります。

## 4. `version.json`（更新マニフェスト）

本体アプリの「更新確認」機能が参照する、**最新バージョン情報**を記述した軽量な設定ファイルです。
配信先（Vercel）のルートに設置します。

### 記述例
```json
{
  "version": "1.9k",
  "downloadUrl": "https://karate-win-pc.vercel.app/karate-all-in-one.html",
  "notes": "・不具合修正と機能改善\n・コート No 入力欄を廃止\n・勝者ボタン連動の敗者自動マーク機能を追加\n・オンライン更新チェック機能を追加"
}
```

### 各項目の説明
| キー | 必須 | 説明 |
| --- | --- | --- |
| `version` | ✅ | 最新バージョン番号（例：`1.9k`, `1.10`, `2.0`）。本体アプリ内の `KW_VER` と比較されます。 |
| `downloadUrl` | ✅ | 最新版本体（`karate-all-in-one.html`）のダウンロード URL。 |
| `notes` | 任意 | 更新内容。ダイアログに表示されます（`\n` で改行）。 |

### バージョン番号の付け方
本体アプリは数値と末尾英字を賢く比較します。以下はすべて正しく「新しい」と判定されます。

- `1.9j` → `1.9k`（末尾英字の繰り上げ）
- `1.9j` → `1.10`（**単純な文字列比較では誤判定しがちな例。数値として 10 > 9 と正しく判定**）
- `1.9j` → `2.0`（メジャー更新）

## 🔄 更新（アップデート）の仕組み

本アプリは完全オフラインで動作しますが、不具合修正・機能追加の配布のために、
**オンライン時のみ**最新版を確認・ダウンロードできる仕組みを備えています。

### 利用者側の操作
1. 本体アプリのトップバー「**更新確認**」ボタンを押す
2. オンラインなら `version.json` を取得し、現行バージョンと比較
3. 新しい版があれば「**⬇ 最新版をダウンロード**」ボタンから取得
4. ダウンロードした `karate-all-in-one.html` で**古いファイルを置き換える**
5. ブラウザで開き直すと最新版が起動（**選手データ・試合結果は同一ブラウザなら引き継がれます**）

> オフライン時・取得失敗時は、アプリを一切壊さず静かにスキップします。通常どおりご利用いただけます。

### 配信者側（メンテナンス）の手順
1. `karate-all-in-one.html` を修正し、本体内の `KW_VER`（例：`window.KW_VER='1.9j';`）を更新
2. `version.json` の `version` を同じ値に更新し、`notes` に変更内容を記載
3. 上記 2 ファイル（必要に応じて `karate-monitor.html` も）を配信先へデプロイ

### 配信 URL の設定箇所
本体アプリ内の設定オブジェクトで、参照先 URL を変更できます。

```js
// karate-all-in-one.html 内
window.KW_UPDATE_CONFIG = {
  manifestUrl: 'https://karate-win-pc.vercel.app/version.json',
  autoCheckOnStart: false   // true にすると起動5秒後に自動でバッジ点灯のみ確認
};
```

## 🚀 デプロイ（Vercel）

配信先ルートに、以下の 3 ファイルを配置します。

```
/ (公開ルート)
├── karate-all-in-one.html
├── karate-monitor.html
└── version.json
```

公開後、次の URL でアクセスできます。

- 本体アプリ：<https://karate-win-pc.vercel.app/karate-all-in-one.html>
- 観客モニター：<https://karate-win-pc.vercel.app/karate-monitor.html>
- 更新マニフェスト：<https://karate-win-pc.vercel.app/version.json>

> **CORS について**：`version.json` は本体アプリから `fetch` で取得します。
> Vercel は既定で許可ヘッダーを付与するため通常は問題ありません。独自サーバーで配信する場合は
> `Access-Control-Allow-Origin` の許可設定が必要です。

## 💾 ローカルでの利用（オフライン運用）

大会当日は、ネットワークが不安定な会場でも安定運用できるよう、
**HTML ファイルをローカルに保存し `file://` で開いて利用**することを推奨します。

1. 配信 URL または GitHub から `karate-all-in-one.html`・`karate-monitor.html` をダウンロード
2. 同じフォルダに置き、`karate-all-in-one.html` をブラウザで開く
3. 「モニター起動」から観客モニターを開き、会場ディスプレイへ全画面表示

> ローカル `file://` でも「更新確認」は動作します（https のマニフェストを取得します）。
